# ぷいぷいプログラム

モルモットのノマドくんを操作して、ブロック(カード)を組み合わせたプログラムを実行し、黒豆(トークン)を集めるビジュアルプログラミング学習ゲームです。

## セットアップ

```bash
npm install
npm run dev
```

`npm run dev` 後、表示される URL(通常 http://localhost:5173 )をブラウザで開いてください。

型チェックのみ行う場合:

```bash
npm run lint
```

本番ビルド:

```bash
npm run build
npm run preview
```

## DB接続について

現状は1人プレイで、サーバー側の状態保持は行っていません。将来スコアの保存・共有機能(対戦・ランキング等)を追加する際は、

1. `.env.example` を `.env.local` にコピー
2. 使う予定のサービス(Firebase など)の値を記入

してください。読み込みは [src/config/env.ts](src/config/env.ts) から行います。`.env*`(`.env.example` を除く)は `.gitignore` で除外されているため、キーをコミットしてしまう心配はありません。

## 仕様書からの実装上の解釈・補足

仕様書の記述だけでは一意に決まらなかった点について、以下のように解釈して実装しています。

- **ラウンドとターンの関係**: 1ラウンド=1枚の地図を5ターン継続して使用します。モルモットの位置・向き・食べた食べ物の状態はターンをまたいで引き継がれます。
- **変数**: ターンごとに0にリセットされます(ターンをまたいで保持しません)。
- **海・地図外に出た場合**: その場でラウンドが終了し、リザルト画面に進みます(残りのターンは消化されません)。
- **「ラベルに戻る」カード**: 仕様書では「条件」カテゴリに分類されていますが、動作の記述(「判断がYもしくはNの場合、指定した位置に戻る」)から、判断カードの条件そのものではなく、Yes/Noレーンの中に置く独立したカードとして実装しています。判断カードの条件には、壁/川/海/変数/食べ物接触/各食べ物の有無の9種類から選びます。
- **地図の描画**: 仕様書ではCanvas/Konvaの使用も検討するとありましたが、5〜20マス四方はCSS Gridで十分に表現できるため、実装をシンプルにするためすべてCSS Gridで描画しています(複雑な地形はマスを「範囲外」として非表示にすることで表現)。

## 技術構成

- TypeScript + React + Vite
- カードのドラッグ&ドロップ: `@dnd-kit`
- 状態管理: React標準の `useReducer` + Context ([src/state](src/state))
- ゲームロジック(プログラムの解釈・採点): [src/engine](src/engine)
